# 1-AND-MORE

**1-AND-MORE** is a freelance e-commerce web application built with the PERN stack (PostgreSQL, Express.js, React.js, Node.js) and styled using Tailwind CSS. The application provides a seamless shopping experience for users and an efficient management system for administrators.

## 🌐 Live Demo

[https://1-and-more.vercel.app](https://1-and-more.vercel.app)

## 🛠️ Features

- User authentication (register/login)
- Admin product management (add/update/delete)
- Shopping cart and checkout
- Order tracking
- Responsive UI with Tailwind CSS

## 🧰 Tech Stack

- **Frontend**: React.js, Tailwind CSS, Axios
- **Backend**: Node.js, Express.js, PostgreSQL, Sequelize

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- PostgreSQL

### Setup

```bash
git clone https://github.com/ali-kamar/1-AND-MORE.git
cd 1-AND-MORE
npm install
cd client && npm install
cd server && npm install
```
### Create a .env file in the server folder:
-DATABASE_URL=your_postgresql_connection_string
-JWT_SECRET=your_jwt_secret

### Run the app
npm run dev
